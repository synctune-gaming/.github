# Synctune Gaming

Synctune Gaming is a branch of [Synctune](https://github.com/synctune-io), focused on independent games and game development. We build games and explore new worlds, mechanics, and ways to play.

## Projects

| Repository | Focus |
| --- | --- |
| [2dnd](https://github.com/synctune-gaming/2dnd) | A browser and desktop role-playing game with exploration and turn-based combat. Soon on Steam. |
| [dungeons-n-scrolls](https://github.com/synctune-gaming/dungeons-n-scrolls) | The Dungeons n Scrolls game project. |
| [eidar-the-miner](https://github.com/synctune-gaming/eidar-the-miner) | The Eidar the Miner game project. |

Repository links use their planned organization locations. Some may be private or pending transfer.
